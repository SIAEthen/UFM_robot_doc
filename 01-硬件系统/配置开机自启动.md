



### jetson开机自启动，利用systemd服务，

#### 不能设置固定IP地址

#### 编写启动脚本

```

#!/bin/bash 

# 初始化ROS环境  #这两行source一定要加，不然不识别ros2环境

source /opt/ros/foxy/setup.bash 

source /home/dongxuyang/fauvms_perception_ws/install/setup.bash

#启动节点命令

ros2 launch your_package your_launch.launch.py

```

赋予执行权限

`sudo chmod +x /path/to/start_ros.sh`

手动试一下脚本能用不

`sudo -u dongxuyang /home/dongxuyang/fauvms_perception_ws/src/perception_start.sh`

#### 创建Systemd服务文件，不要有中文

在/etc/systemd/system/下创建服务文件（如ros2_auto.service）：

`sudo vim /etc/systemd/system/ros2_auto.service`

```

[Unit]

Description=ROS 2 AutoLaunch

After=multi-user.target

[Service]

Type=simple

User=dongxuyang

ExecStart=/home/dongxuyang/fauvms_perception_ws/src/perception_start.sh

WorkingDirectory=/home/dongxuyang

Restart=on-failure

ExecStartPre=/bin/sleep 10

[Install]

WantedBy=multi-user.target

```

ExecStartPre=/bin/sleep 10 为延时启动，十分重要

#### 启用服务

启用ros2服务

```

sudo systemctl daemon-reload 

sudo systemctl enable ros2_auto.service  # 开机自启 

sudo systemctl start ros2_auto.service   # 立即启动

```

验证状态

`sudo systemctl status ros2_auto.service`

不能用可以check一下问题

`sudo journalctl -u ros2_auto.service --since "5 minutes ago" --no-pager`

#### 下面可选

启用网络等待服务

`sudo systemctl enable systemd-networkd-wait-online.service  # 对systemd-networkd后端，netplan默认就是这个`

验证状态

`systemctl status network-online.target  # 状态应为active`

看看启动顺序（估计需要成功启动才可以查看）

`systemd-analyze critical-chain ros2_auto.service`

#### 取消服务

取消服务下次运行

sudo systemctl disable ros2_auto.service

停止服务当前运行

sudo systemctl stop  ros2_auto.service

重启服务运行

sudo systemctl restart  ros2_auto.service

查看服务运行状态

sudo systemctl status  ros2_auto.service

编辑文件内容

sudo vim /lib/systemd/system/ ros2_auto.service

查看服务输出内容

journalctl -u  ros2_auto -e

#### 常见问题

```

​​环境变量冲突​​：在.sh和.bashrc中统一设置ROS_DOMAIN_ID。

​​权限问题​​：

免密码sudo：在/etc/sudoers添加 your_username ALL=(ALL) NOPASSWD:ALL。

自动登录：在系统设置中启用自动登录。

```
